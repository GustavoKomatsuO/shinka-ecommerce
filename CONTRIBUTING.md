# Contribuindo

Abra uma issue com o problema ou proposta. Para alterar o código, crie uma branch como `feat/catalogo` ou `fix/carrinho` e abra uma pull request com motivação, mudança e passos de validação.

Use títulos de commit como `feat: adiciona filtro de produtos`, `fix: corrige total do carrinho` ou `docs: atualiza instalação`.

Antes da PR, confira sintaxe PHP/JavaScript e teste o fluxo afetado com dados fictícios. Não versione credenciais, configurações locais, dados reais de clientes nem uploads de usuários.
